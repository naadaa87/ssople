쏘플 퀴즈쇼

문제와 보기 네 개가 크게 뜨고, 제한 시간이 줄어드는 동안 팀끼리 머리를 맞대요. 진행자는 정답을 공개하고 맞힌 팀만 누르면 점수가 쌓여요. 마지막 문제는 2배라서 끝까지 순위가 뒤집혀요.

폰 연결 체험판
인원
2~20명 (2~4팀)
시간
10문제 10분 안팎
준비물
TV나 노트북 한 대, 진행자 한 명
잘 맞는 모임
송년회, 워크숍, 동창회, 가족 모임

이렇게 진행해요

  1. 진행자 한 명을 정하고, 파티룸 TV에 이 화면을 띄워요. 리모컨이나 노트북 키보드의 엔터로도 넘길 수 있어요.
  2. 주제와 문제 수, 제한 시간을 고르고 2~4팀으로 나눠요. 팀 이름은 마음대로 바꿔도 돼요.
  3. 문제가 뜨면 팀끼리 상의해서 답을 정해요. 답은 "빨강!", "세모!"처럼 색이나 도형으로 외치면 헷갈리지 않아요.
  4. 시간이 끝나거나 진행자가 정답 공개를 누르면 정답이 표시돼요. 맞힌 팀을 눌러 점수를 줘요. 여러 팀이 맞혔으면 모두 누르면 돼요.
  5. 마지막 문제는 점수가 2배예요. 끝나면 팀 순위가 크게 떠요.

답을 받는 세 가지 방법

방법 이렇게 해요 잘 맞는 상황
외치기 팀장이 색이나 도형을 크게 외쳐요 4~10명, 분위기를 띄울 때
손 들기 팀마다 답 카드(빨·파·노·초)를 들어요 15명 넘는 단체
종이에 쓰기 팀마다 화이트보드나 종이에 번호를 적어요 조용히 해야 하는 밤 시간

외치기 방식은 먼저 외친 팀만 인정할지, 시간 안에 낸 팀 모두 인정할지 시작 전에 정해 두세요. 다툼이 확 줄어요.

주제 고르는 요령

  • 섞어서: 상식·넌센스·음식·스포츠·지리·문화·쏘플 특집을 고루 섞어요. 처음이라면 이걸로.
  • 넌센스: 술자리나 밤 시간에 웃음이 제일 커요. 정답을 듣고 다 같이 탄식하는 맛이 있어요.
  • 키즈: 아이들도 풀 수 있는 쉬운 문제예요. 가족 모임이나 아이 생일파티에서 어른 팀 대 아이 팀으로 붙여 보세요.
  • 쏘플 특집: 파티룸 이용 규칙이 문제로 나와요. 첫 문제 몇 개로 깔면 퇴실 정리 안내도 자연스럽게 돼요.

더 재밌게 하는 요령

  • 10문제 기준으로 10분 안팎이 걸려요. 20문제는 중간에 쉬는 시간을 한 번 넣는 게 좋아요.
  • 점수 차가 크게 벌어지면 진행자 재량으로 "다음 문제 3배"를 걸어도 돼요. 이 화면은 맞힌 팀에 1점(마지막 문제는 2점)씩만 더해 주니, 배수로 더 줄 점수는 진행자가 메모해 두었다가 결과 발표 때 더해 주세요.
  • 상품은 크지 않아도 돼요. 1등 팀이 다음 게임 순서를 정하거나, 꼴찌 팀이 정리 담당을 맡는 정도로도 충분히 진지해져요.
  • 직접 만든 문제로 하고 싶다면 파티 퀴즈 문제 만드는 법을 참고해 종이로 몇 문제 섞어 보세요.

퀴즈쇼 문제 예시

주제마다 25문제 안팎이 들어 있어요. 몇 문제만 미리 보여 드려요. 정답은 굵게 표시했어요.

자주 묻는 질문

몇 명까지 할 수 있나요?
팀 대항이라 인원 제한은 사실상 없어요. 2~4팀으로 나누고, 팀이 6명을 넘으면 팀장이 답을 외치게 하면 깔끔해요.
문제가 겹치지 않나요?
주제마다 문제가 25개 안팎이고, 섞어서를 고르면 170개가 넘는 문제 중에서 무작위로 뽑아요. 같은 날 두세 판은 거의 겹치지 않아요.
제한 시간 없이도 되나요?
네. 제한 시간을 없음으로 두면 진행자가 정답 공개를 누를 때까지 기다려요. 아이들과 할 때 편해요.
점수는 어디에 저장되나요?
이 화면에서만 계산하고 어디에도 보내지 않아요. 창을 닫으면 사라져요.
