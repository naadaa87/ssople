밸런스 게임

A와 B 중 하나만 골라야 하는 질문이 떠요. 셋을 세면 동시에 고르고, 몇 명씩 골랐는지 세어 넣으면 비율이 나와요. 적은 쪽을 고른 사람이 왜 그걸 골랐는지 해명하는 순간이 이 게임의 하이라이트예요.

폰 연결 체험판
인원
2~20명
시간
10문제 5~10분
준비물
TV나 폰 한 대
잘 맞는 모임
처음 만난 모임, 워크숍, 커플 모임, 동아리

이렇게 진행해요

  1. 질문 묶음(섞어서·음식·연애·직장·여행·상상·쏘플 특집)과 질문 수, 고르는 방법을 정해요.
  2. 질문이 뜨면 진행자가 A와 B를 읽어요. 왼쪽 빨강이 A, 오른쪽 파랑이 B예요.
  3. 하나, 둘, 셋!을 누르면 3초를 센 뒤 동시에 골라요.
  4. 몇 명씩 골랐는지 숫자를 넣으면 비율 막대가 나와요. 귀찮으면 숫자 없이 넘어가도 돼요.
  5. 적은 쪽을 고른 소수파가 이유를 말해요. 같은 수라면 양쪽에서 한 명씩.
  6. 끝나면 오늘 고른 결과를 한 화면에 모아 보여 줘요.

고르는 방법 세 가지

방법 이렇게 해요 장점
주먹·보자기 A는 주먹, B는 보자기를 동시에 내요 앉은 채로 빠르게, 눈치 보기 어려워요
자리 이동 A는 왼쪽, B는 오른쪽으로 걸어가요 몸을 움직여서 분위기가 살아나요. 넓은 지점에서
손 들기 A 고른 사람 손, 그다음 B 20명 넘는 단체에서 세기 쉬워요

질문 묶음 고르는 요령

  • 처음 만난 사이: 섞어서나 음식, 여행. 정답이 없는 가벼운 취향 질문이라 누구나 말을 꺼내기 쉬워요.
  • 회사·동아리: 직장 묶음은 "주 4일 하루 10시간 vs 주 5일 하루 8시간"처럼 이야기가 길어지는 질문이 많아요.
  • 커플·친한 친구: 연애 묶음. 서로의 답을 미리 예상해 보고 맞히는 식으로 바꿔도 재밌어요.
  • 아무 말 대잔치가 필요할 때: 상상 묶음. "하늘을 나는 능력 vs 순간 이동 능력" 같은 질문은 정답이 없어서 오래 떠들어요.

더 재밌게 하는 요령

  • 눈치 모드로 바꾸기: 내 취향이 아니라 "다수가 고를 것 같은 쪽"을 골라요. 다수파에 든 사람만 1점.
  • 커플 궁합 모드: 두 사람이 등을 맞대고 동시에 골라요. 몇 문제나 같았는지 세면 궁합 점수가 돼요.
  • 해명 시간 15초: 소수파 해명이 길어지면 놀이터의 타이머로 15초를 걸어 두세요.

밸런스 게임 질문 예시

묶음마다 50개씩, 모두 300개가 들어 있어요. 그중 일부를 묶음별로 모았어요.

자주 묻는 질문

밸런스 게임 질문은 몇 개나 있나요?
음식·연애·직장·여행·상상·쏘플 특집 여섯 묶음에 50개씩, 모두 300개예요. 다른 질문 버튼으로 마음에 안 드는 질문은 바로 바꿀 수 있어요.
꼭 숫자를 세야 하나요?
아니요. 숫자 없이 결과 보기를 누르면 비율 없이 넘어가요. 소수파가 누군지는 눈으로 봐도 충분해요.
아이들과 해도 되나요?
음식과 상상 묶음은 아이들도 쉽게 고를 수 있어요. 연애·직장 묶음은 빼는 게 좋아요.
놀이터의 밸런스 게임과 무엇이 다른가요?
놀이터의 밸런스 게임은 질문 카드만 넘기는 간단한 도구예요. 여기는 묶음 고르기, 3초 카운트, 인원 비율, 결과 모아 보기까지 진행이 붙어 있어요.
바로 해 볼까요?

TV에 이 화면을 띄우고 시작을 누르면 게임 무대로 바뀌어요.
