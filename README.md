# 쏘플파티룸 고객 홈페이지

전국 쏘플파티룸 지점 정보와 요금을 보여 주고, 예약은 **네이버 예약**으로 연결하는 고객용 홈페이지예요.
커뮤니티, 모임, 파티팀 모집, 행사, 놀이터(파티 도구), 초대장, 쏘플 클럽(멤버십), 제휴·협업까지 한 사이트에 담았어요.

- 예약·결제·취소: 네이버 예약에서 해요. 이 홈페이지는 결제를 받지 않아요.
- 예약 버튼: 패키지별 네이버 예약 상품 → 지점 네이버 예약 페이지 → 네이버 지도 순서로 연결해요. (운영지점리스트 2026.10.11 기준 36곳 공개)
- 빈 방 표시: 관리자 화면에서 네이버 예약 엑셀을 올리거나 직접 방막기로 채워요. 호스트 센터 연결은 지금 꺼 두었고, 나중에 `wrangler.toml`에서 켤 수 있어요.
- 운영: `/admin` 관리 화면에서 방막기, 엑셀 올리기, 지점·행사·커뮤니티·회원 관리를 해요.

## 배포

배포 안내서와 운영 안내서는 전달한 ZIP의 `docs` 폴더에 따로 들어 있어요. 내부 운영 내용이라 저장소(=공개 홈페이지)에는 올리지 않아요. 요약하면:

1. Cloudflare D1에서 `ssople-web` 데이터베이스 만들기
2. Pages(ssople) → Settings → Variables and Secrets에 `ADMIN_PASSWORD`(Secret) 추가
3. `wrangler.toml`의 `database_id` 자리에 ID 붙여넣기 (올리기 전에 — 빠지면 배포가 실패해요)
4. GitHub 저장소의 예전 파일 모두 지우기
5. 두 번에 나눠 업로드: ① assets·functions를 뺀 나머지 ② assets·functions
6. `/api/health`, `/admin`에서 확인

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `*.html` | 화면 (홈, 지점 찾기, 지점 상세, 행사, 모임, 파티팀, 커뮤니티, 놀이터, 초대장, 쏘플 클럽, 마이, 관리자, 약관 등) |
| `assets/` | 공통 스타일·스크립트, 화면별 스크립트, 공유 이미지·아이콘 |
| `functions/` | 서버 기능 (Cloudflare Pages Functions) — API, 공유 미리보기, 사이트맵 |
| `functions/_lib/seed-spaces.js` | 지점 공개 정보와 네이버 예약 링크 (45곳 중 36곳 공개, 내부 정보 제외) |
| `wrangler.toml` | DB·사진 저장소 연결 설정 |
| `_routes.json` | 서버 기능을 거치는 주소 목록 |
| `_redirects` | 설정 파일(README, wrangler.toml 등)이 홈페이지 주소로 열리지 않게 막기, 예전 주소 옮기기 |

## 연결

| 이름 | 종류 | 용도 |
|---|---|---|
| `DB` | D1 `ssople-web` | 회원, 커뮤니티, 모임, 행사, 방막기, 설정 (처음 접속할 때 자동 설치) |
| `PHOTOS` | R2 `ssople-photos` | 사진 |
| `ADMIN_PASSWORD` | Secret | 관리자 로그인 |
| `HOSTDB` | D1 (지금은 끔) | 나중에 호스트 센터를 다시 쓸 때 예약 읽기 전용 |
| `SYNC_TOKEN` | Secret (나중에) | 호스트 예약 자동 업데이트·외부 예약 수신 |
