내 파티룸을
쏘플에 올려 보세요

파티룸을 운영하는 호스트라면 누구나 쏘플 플랫폼에 공간을 등록할 수 있어요. 쏘플이 승인하면 지점 화면이 열리고, 예약은 네이버 예약으로 바로 이어져요. 운영까지 맡기고 싶다면 위탁운영을, 새로 열고 싶다면 창업 상담을 골라 주세요.

01 · 공간 등록

운영 중인 파티룸,
쏘플 손님에게 보여 주세요

쏘플 홈페이지는 "파티룸", "지역 이름 + 파티룸", "생일파티 장소" 같은 검색어로 손님이 들어오는 곳이에요. 공간을 등록하면 지점 목록, 지역·동네 화면, 목적별 추천에 함께 노출되고, 손님은 지점 화면에서 바로 호스트의 네이버 예약으로 넘어가요. 쏘플이 예약을 대신 받거나 응대하지는 않아요. 쏘플파티룸 플랫폼에 등록·노출만 해 드리고, 정보 안내·홍보 관리·고객 소통은 호스트가 직접 하는 방식이에요.

  • 등록 신청 → 쏘플 검토·승인 → 지점 화면 오픈 (보통 영업일 3일 안)
  • 호스트 계정을 드려요. 소개·사진·시설·요금·지점 소식을 직접 올릴 수 있어요
  • 지점 화면의 예약 버튼은 호스트의 네이버 예약 상품으로 연결돼요
  • 후기·방문 인증·커뮤니티 같은 쏘플 기능이 그대로 붙어요
공간 등록 요금

기간이 길수록 하루 요금이 낮아져요

쏘플파티룸 플랫폼에 등록·노출되고, 정보 안내·홍보 관리·고객 소통은 호스트가 직접 하는 방식이에요. 월 요금 외에 별도 수수료는 없어요.

공간 등록 신청

손님과의 예약·결제·환불은 호스트의 네이버 예약 조건을 따라요. 결제 방법과 세금계산서 발행은 승인 안내 때 함께 알려 드려요.

02 · 위탁운영

예약부터 응대까지,
쏘플이 대신 운영해요

예약 관리, CS, 고객 응대, 예약 채널 운영, 홍보 마케팅을 쏘플 본사가 맡아요. 호스트는 청소·비품·시설 관리만 하면 돼요. 결제 수수료를 포함해 매출의 20%를 쏘플이 받고, 별도의 월 이용료는 없어요.

쏘플이 하는 일

  • 네이버 예약 등 채널 등록·운영
  • 예약 확정·변경·취소·환불 처리
  • 고객 문의 응대 (카카오톡·전화)
  • 홍보 마케팅 · 후기 관리
  • 매달 정산서 (1일 집계 · 5일 확인 · 10일 지급)

호스트가 하는 일

  • 이용 전후 청소·정리 (외주 연결 가능)
  • 소모품 채우기 · 비품 확인
  • 시설 점검과 간단한 보수
  • 현장 문제 1차 확인

진행 순서

신청부터 노출까지

  1. 신청

    아래 폼이나 카카오톡으로 공간 이름·주소·네이버 예약 주소를 보내 주세요.

  2. 검토 · 승인

    공간 사진과 운영 상태를 확인하고 영업일 3일 안에 결과를 알려 드려요.

  3. 지점 화면 만들기

    호스트 계정으로 소개·사진·요금·시설을 채워요. 쏘플이 처음 세팅을 도와 드려요.

  4. 노출 시작

    지점 목록·지역 화면·검색에 올라가고, 예약은 네이버 예약으로 이어져요.

자주 묻는 질문

쏘플이 예약을 대신 받아 주나요?
공간 등록(01)은 노출만 해 드려요. 손님은 지점 화면에서 호스트의 네이버 예약으로 넘어가서 직접 예약·결제해요. 예약 관리와 응대까지 맡기고 싶다면 위탁운영(02)을 골라 주세요.
네이버 예약을 아직 안 쓰고 있어요.
네이버 스마트플레이스에서 예약 상품을 먼저 만들어 주세요. 어렵다면 신청할 때 적어 주시면 세팅 방법을 안내해 드려요. 위탁운영은 쏘플이 채널 세팅까지 해 드려요.
공간 등록 요금은 기간마다 어떻게 다른가요?
1개월, 3개월, 6개월, 12개월 중에 고를 수 있고, 기간이 길수록 하루 요금이 낮아져요. 기간별 요금은 위 요금표와 같아요. 월 요금 외에 예약 수수료 같은 별도 수수료는 없어요.
결제는 어떻게 하나요?
승인 안내와 함께 결제 방법과 세금계산서 발행, 중도 해지 기준을 알려 드려요.
위탁운영 20%에는 무엇이 들어 있나요?
예약 채널 결제 수수료, 예약 관리, 고객 응대, 채널 운영, 홍보 마케팅, 정산 시스템 사용료가 모두 들어 있어요. 별도로 청구하는 월 이용료는 없어요.
호스트 계정으로 무엇을 할 수 있나요?
내 지점의 소개·사진·시설·이용 안내를 고치고, 지점 소식 글을 올려 손님과 소통할 수 있어요. 공간 등록 호스트는 요금과 네이버 예약 주소도 직접 관리해요. 로그인 뒤 마이 → 내 공간 관리에서 써요.
여러 공간을 함께 등록할 수 있나요?
네. 공간마다 지점 화면이 따로 만들어지고, 이용 기간도 공간마다 골라요. 세 곳 이상이면 신청할 때 적어 주세요. 묶음 조건을 안내해 드려요.
